# Working notes for Claude

## Writing style

- **Never use dashes as punctuation** (em dash, en dash, `&mdash;`,
  `&ndash;`) in any written copy: page text, meta tags, alt text, titles,
  commit messages, or anywhere else prose appears in this repo. Rewrite the
  sentence instead. Split it into two sentences, or use a comma, colon, or
  "and"/"including" depending on what reads best. This applies going
  forward to all new writing, not just a one-time cleanup.
  - Ordinary hyphens inside compound words (`non-SQL`, `AI-generated`,
    `e-commerce`, `cross-functional`) are fine. This rule is about the
    dash-as-punctuation pattern, not hyphenation.
  - Date ranges (`2024 to Present`, `Sep 2024–Present`) haven't been
    resolved yet: `cv-master.md` still uses en dashes for these. Ask before
    changing that file's convention.
